# Sample Medical Library

This is a template structure for organizing medical records.

## Structure

- **lab-results/** — Blood work, metabolic panels, imaging reports
- **medications/** — Current medications and history
- **doctor-notes/** — Consultations, referrals, follow-ups
- **hospital-visits/** — Emergency visits, discharge summaries
- **symptoms/** — Daily tracking, symptom history
- **imaging/** — MRI, CT scan, X-ray reports
- **procedures/** — Surgical procedures, treatments

## Tips

- Use Markdown (`.md`) files for text records
- Convert PDFs from patient portals to Markdown before adding
- Use tables for lab results with clear columns
- Date files: `YYYY-MM-DD-description.md`
- Keep descriptions concise and descriptive

## Note

This is a template structure. Replace this README with your own notes once you populate the library with your records.
